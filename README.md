One original funny line for make.fun's "One Line, One Laugh" bounty: "My smart fridge texted me at 3 a.m. to say the milk expired, then asked if I wanted more milk ordered or just to be judged in silence."

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (134 characters, inside the 140-character gate).

## How it works

The joke is a two-beat one-liner: a concrete, specific setup (a smart fridge texting at 3 a.m. about expired milk) with an absurd twist (the fridge offering to judge you in silence instead of just reordering). `main.py` holds the line as a constant, checks it against the 1–140 character gate, writes it with no trailing newline so the file is exactly the line, and leaves the output world-readable (mode 0644) so the grader can collect it. The program is fully deterministic: every run writes the same bytes.
